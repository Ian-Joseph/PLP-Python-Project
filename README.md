# PLP-Python-Project
# COVID-19 Global Data Tracker 🦠📊

## Project Description
This project analyzes global COVID-19 data trends, including cases, deaths, recoveries, and vaccinations, using Python data tools.

## Objectives
✅ Import and clean COVID-19 data  
✅ Analyze time trends (cases, deaths, vaccinations)  
✅ Compare metrics across countries  
✅ Visualize trends with charts and maps  
✅ Present findings in a Jupyter Notebook/PDF report  

## Tools & Libraries
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Folium (for maps)
